# 内容生成规范

## PPT（幻灯片 HTML）规范

### 页面结构

每页 PPT 包含：
- **页面标题**：一句话概括本页核心观点。
- **正文内容**：3-5 个要点，每个要点不超过两行。
- **视觉元素**（按需）：代码块、表格、示意图、关键数据高亮。
- **页码**：底部显示 "当前页 / 总页数"。

### 内容原则

1. **一页一观点**：不要在一页塞多个不相关的主题。
2. **要点化**：用短句和列表，不写大段文字。
3. **关键词加粗**：核心术语用加粗或高亮色标注。
4. **渐进呈现**：复杂概念拆成多页，每页推进一层。
5. **首尾呼应**：章节首页为"本章目标"，末页为"本章小结"。

### 典型页面类型

| 页面类型 | 用途 | 内容结构 |
|---------|------|---------|
| 章节封面 | 章节开始 | 章节名 + 一句话简介 + 知识点列表 |
| 概念讲解 | 介绍新概念 | 定义 + 关键特征 + 简单示例 |
| 原理图解 | 讲机制/流程 | 图示 + 分步说明 |
| 代码演示 | 展示代码 | 代码块 + 关键行注释 + 运行结果 |
| 对比分析 | 方案/概念对比 | 对比表格 + 适用场景 |
| 案例分析 | 实际应用 | 问题背景 + 解决方案 + 结果 |
| 本章小结 | 章节结束 | 核心要点回顾 + 下章预告 |

## 课件（讲义 HTML）规范

### 页面结构

课件为单页长文档，包含：
- **顶部标题栏**：课程名 + 章节名。
- **左侧导航**：本章知识点锚点目录，点击跳转。
- **正文区域**：按知识点分节，每节包含详细讲解。
- **底部**：本章小结 + 思考题/练习题。

### 内容原则

1. **比 PPT 详细**：PPT 是提纲，课件是完整讲义。
2. **有推导有解释**：公式给出推导过程，概念给出类比和例子。
3. **代码有注释**：代码块逐行或逐段注释，说明为什么这么写。
4. **有小结有思考**：每节末尾有简短小结，章末有思考题。
5. **引用可追溯**：如引用外部资料，标注来源链接或文献。

### 课件章节模板

```
# 第N章：章节名称

## 本章学习目标
- 目标1
- 目标2

## 1. 知识点一名称
### 1.1 概念定义
（详细解释）

### 1.2 核心原理
（原理说明 + 公式/图示）

### 1.3 示例
（代码/案例 + 说明）

### 1.4 小结
（2-3 句话总结本节）

## 2. 知识点二名称
...

## 本章小结
（核心要点汇总）

## 思考题
1. 问题一
2. 问题二
```

## HTML 技术规范

### 通用要求

- **自包含**：所有 CSS 和 JS 内联在 HTML 文件中，不引用外部文件。
- **离线可用**：不依赖 CDN、网络字体或外部图片。
- **编码**：UTF-8，`<meta charset="UTF-8">`。
- **响应式**：PPT 适配 16:9 投影比例；课件适配桌面浏览器宽度。

### PPT 交互

- 支持键盘 ← → 方向键和空格键翻页。
- 支持点击页面左右区域翻页（可选）。
- 显示当前页码和总页数。
- 页面切换有简单过渡动画（CSS transition）。

### 课件交互

- 左侧导航固定，点击锚点平滑滚动。
- 代码块支持等宽字体显示。
- 表格有边框和斑马纹。
- 支持打印样式（可选）。

### 配色与排版

- 主色调：深蓝 (#1a365d) 作为标题和强调色。
- 辅助色：浅灰背景 (#f7fafc)，正文深灰 (#2d3748)。
- 代码块：深色背景 (#1a202c)，浅色文字 (#e2e8f0)。
- 字体：系统无衬线字体栈 `system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`。
- 代码字体：`Consolas, "Courier New", monospace`。

## 质量检查清单

生成每章内容后，自检以下项目：

- [ ] PPT 页数与知识点数量匹配（5-15 页）
- [ ] PPT 每页一个核心观点，无大段文字
- [ ] 课件覆盖目录中该章所有知识点
- [ ] 课件包含学习目标、小结、思考题
- [ ] 代码块有注释，可运行（如为代码类内容）
- [ ] HTML 自包含，无外部依赖
- [ ] 文件名符合 `chapter-{N}-ppt.html` / `chapter-{N}-courseware.html`
- [ ] 无事实性错误（技术概念、公式、代码语法）
