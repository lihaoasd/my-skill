# 教学内容制作 Skill

## 核心原则

- **目录先行**：未确认章节目录前，不生成任何章节内容。
- **逐章推进**：一次只处理一个章节，该章节审核通过后才进入下一章。
- **双产物并行**：每个章节同时产出 PPT（幻灯片式 HTML）和课件（讲义式 HTML）。
- **用户审核为关卡**：目录和每章内容都必须经用户确认，禁止跳过审核直接推进。
- **修改闭环**：用户提出修改后，修改对应产物并重新提交审核，不静默修改。

## 工作总流程

```
阶段一：目录制定与审核
  ├─ 收集课程信息（主题、受众、课时、深度）
  ├─ 生成章节目录 + 每章知识点清单
  ├─ 用户审核 → 修改 → 确认
  └─ 目录锁定，进入阶段二

阶段二：逐章内容生成（循环，直到所有章节完成）
  ├─ 确认当前章节及内容来源要求
  ├─ 生成该章 PPT（HTML）
  ├─ 生成该章课件（HTML）
  ├─ 用户审核 → 修改 → 确认
  └─ 进入下一章

阶段三：汇总交付
  ├─ 汇总所有章节产物
  └─ 提供文件清单与使用说明
```

## 阶段一：目录制定与审核

### 1.1 信息收集

向用户确认以下信息（用户已提供的跳过）：

| 字段 | 说明 |
|------|------|
| 课程主题 | 课程名称与核心内容 |
| 目标受众 | 学生/职场新人/专业人员等 |
| 总课时 | 预计章节数或总时长 |
| 内容深度 | 入门/进阶/高级 |
| 特殊要求 | 是否需要案例、代码、习题、参考资料等 |

### 1.2 生成目录

按以下结构输出目录草案：

```
课程名称：XXX

第1章：章节名称
  知识点1：...
  知识点2：...
  知识点3：...

第2章：章节名称
  ...
```

目录要求：
- 章节之间逻辑递进，不重复、不遗漏核心主题。
- 每章知识点 3-8 个，粒度适中（一个知识点可对应 1-3 页 PPT）。
- 标注每章预计页数/时长（可选）。

### 1.3 用户审核与修改

- 将目录提交给用户，明确询问："请审核目录，可提出增删改，确认后开始逐章生成。"
- 用户提出修改后，更新目录并重新提交，直到用户明确确认。
- 目录确认后，输出一句锁定声明："目录已确认，共 N 章，开始生成第 1 章。"

详细目录模板与示例见 [references/outline-guide.md](references/outline-guide.md)。

## 阶段二：逐章内容生成

### 2.1 章节启动

每章开始前，向用户确认：
- 当前章节编号与名称。
- **内容来源要求**：是否需要基于特定资料（用户上传的文档/链接）、是否需要联网搜索、是否纯原创。
- 该章是否有特殊侧重（如重点讲某个知识点、增加案例等）。

如果用户指定了内容来源，先读取/搜索来源材料，再开始生成。

### 2.2 生成 PPT（HTML）

- 使用 `assets/ppt-template.html` 作为基础模板。
- PPT 为全屏幻灯片式 HTML，铺满浏览器窗口，支持键盘左右键/空格翻页、顶部进度条。
- 每页一个核心观点，标题 + 要点 + 必要的图示/代码/表格。
- 页数与该章知识点匹配，通常 5-15 页。
- 文件名：`chapter-{N}-ppt.html`

PPT 内容规范与模板使用说明见 [references/content-standards.md](references/content-standards.md)。

### 2.3 生成课件（HTML）

- 使用 `assets/courseware-template.html` 作为基础模板。
- 课件为讲义式长页面 HTML，带侧边章节目录导航。
- 内容比 PPT 详细：包含概念解释、推导过程、案例分析、代码注释、小结、思考题。
- 文件名：`chapter-{N}-courseware.html`

### 2.4 提交审核

两个产物生成后，通过 `present_files` 交付给用户，并说明：
- 当前章节名称。
- PPT 页数、课件主要内容板块。
- 明确询问："请审核本章内容，可提出修改意见；确认后进入下一章。"

### 2.5 修改处理

- 用户提出修改时，精准定位到 PPT 或课件的具体部分进行修改。
- 修改后重新交付修改后的文件，并说明改了什么。
- 同一章节可多轮修改，直到用户确认。
- 用户确认后，输出："第 N 章已确认，开始生成第 N+1 章：XXX。"

修改处理的详细流程见 [references/revision-handling.md](references/revision-handling.md)。

## 阶段三：汇总交付

所有章节完成后：
1. 生成课程总目录索引页 `index.html`，使用 `assets/index-template.html` 作为模板，列出所有章节卡片，每个卡片链接到对应章节的 PPT 和课件。
2. 列出全部产物文件清单（索引页 + 各章节 PPT + 各章节课件）。
3. 说明文件打开方式：用浏览器打开 `index.html` 即可从目录页进入任意章节。

## 产物存放

- 所有 HTML 文件输出到当前工作目录下的 `output/` 子目录。
- 目录草案、修改记录等中间文本直接在对话中呈现，不单独存文件（用户要求时除外）。

## 注意事项

- 不要在未确认目录时生成内容。
- 不要同时生成多个章节。
- 不要跳过用户审核环节。
- HTML 必须自包含（内联 CSS/JS），不依赖外部 CDN，确保离线可打开。
- 中文字体使用系统默认字体栈，不嵌入字体文件。
